# 三趟 Shellsort 的最优平均成本

**摘要。** 本文研究均匀随机排列上、间隔表在输入前固定的三趟 Shellsort。对于成功右移数和实际键比较数两种计费，分别证明最优平均成本为 $\Theta(n^{3/2})$，并给出显式非渐近界。上界由表族 $(q^2+1,q,1)$、$q=\lfloor n^{1/4}\rfloor$ 达到；下界对所有合法三趟表成立。证明以局部净位移 $F_k$ 连接排序成本与全局位移，结合互素两趟位移上界和两个波动下界完成。

**关键词。** Shellsort；平均复杂度；三趟排序；位移估计。

## 1. 模型与计费

输入为 $n$ 个互异键，等价地视为 $\{0,1,\dots,n-1\}$ 的均匀随机排列。预先选定间隔表 $(h,g,1)$，其中 $n>h>g\ge2$ 为整数。每一趟对间隔 $k$ 的各条链，即位置 $r,r+k,r+2k,\dots$，执行普通线性插入排序。

采用以下两种计费：

- $M_i$ 为第 $i$ 趟中较大前驱右移一个链内位置的次数，称为成功右移数；$M=M_1+M_2+M_3$。
- $C_i$ 为第 $i$ 趟的键比较次数，包括使扫描停止的比较（若存在）；$C=C_1+C_2+C_3$。

一次右移对应一次成功比较，每次插入至多另有一次终止比较。因此，逐输入有

$$
M\le C\le M+(n-h)+(n-g)+(n-1)\le M+3n.
$$

本文分别研究两个有限最小值

$$
\min_{n>h>g\ge2}\mathbb E\,M(h,g,1),
\qquad
\min_{n>h>g\ge2}\mathbb E\,C(h,g,1).
$$

间隔表可随 $n$ 变化，并在读取输入前固定；两个目标分别取最小值。

## 2. 主定理

**定理 A（三趟最优平均成本）。** 对每个整数 $n\ge16$，

$$
\frac{n\sqrt n}{65536}\le
\min_{n>h>g\ge2}\mathbb E\,M
\le4n\sqrt n,
\qquad
\frac{n\sqrt n}{65536}\le
\min_{n>h>g\ge2}\mathbb E\,C
\le5n\sqrt n.
$$

因此，最优平均右移数与最优平均比较数均为 $\Theta(n^{3/2})$。上界由同一张显式表 $(q^2+1,q,1)$、$q=\lfloor n^{1/4}\rfloor$ 达到，下界对每一张合法表成立。

**定理 B（互素两趟位移上界）。** 在均匀输入下，若 $1\le g<h<n$ 且 $\gcd(h,g)=1$，则

$$
\mathbb E\,F(S_gS_hA)
\le
\frac{n(g-1)\sqrt{h+3}}{2}.
$$

其中 $S_kA$ 表示将位置模 $k$ 的各条链分别排好后的数组。全局位移（Spearman 足距）定义为

$$
F(A)=\sum_x|P_x-R_x|,
$$

$P_x$ 和 $R_x$ 分别为键 $x$ 的位置与秩，均从 $0$ 起编号。

## 3. 记号与随机化约定

| 记号 | 含义 |
|---|---|
| $I_k(A)$ | 间隔 $k$ 的链内逆序数：$\#\{(i,j):i<j,\ i\equiv j\pmod k,\ A_i>A_j\}$ |
| $F(A)$ | 全局位移 $\sum_x\lvert P_x-R_x\rvert$ |
| $F_k(A)$ | 局部净位移 $\frac1k\sum_x\lvert P_x-Q_{k,x}\rvert$，其中 $Q_{k,x}$ 为键 $x$ 在 $S_kA$ 中的位置；$F_1=F$ |
| $S_kA$ | 对模 $k$ 各链排序后的状态 |
| $M_i,C_i$ | 第 $i$ 趟的成功右移数、键比较数 |
| $L_s$ | 第 $s$ 条 $h$-链的长度；若 $n=mh+r$，则 $L_s=m+1$（$s<r$），$L_s=m$（$s\ge r$） |
| $t$ | 按原始位置指定的键（枢轴）的键值 |
| $Y_s$ | 源链 $s$ 中小于枢轴的键数，枢轴自身不计 |
| $D_{hg}$ | 两趟后枢轴的位置与秩之差 |
| $m$ | $\lfloor n/h\rfloor$，即下界引理中的链长基数 |
| $s$ | $\sqrt n$，用于上界构造与四情形下界的计算 |

**随机化约定。** 在各原始位置独立放置均匀分布于 $[0,1]$ 的实数，再替换为秩，得到均匀随机排列。枢轴按原始位置指定；给定其键值 $t$ 后，其余原始位置上的键是否小于枢轴，构成条件独立的 $\mathrm{Bernoulli}(t)$ 试验。

## 4. 证明概述与篇章安排

确定性部分以

$$
I_k(A)\le F_k(A)\le2I_k(A)
$$

及

$$
|F(A)-F(S_kA)|
\le kF_k(A)
\le F(A)+F(S_kA)
$$

连接单趟成本与全局位移。

上界使用首趟估计和定理 B 控制第二、第三趟的平均右移数，再取 $(h,g)=(q^2+1,q)$。由 $M\le C\le M+3n$，得到定理 A 的两个上界。

下界使用引理 3.1 的首趟位移波动和引理 3.2 的圆弧计数波动，结合位移偿还式，依次处理 $h^2\le n$、$g^2\le h$、$\gcd(h,g)>1$ 以及其余互素情形，得到对所有合法表统一成立的下界。

## 5. 本文贡献与相关工作

Janson–Knuth 的三趟分析建立了圆弧计数结构，并在特定间隔尺度上得到 $O(n^{23/15})$ 的平均上界。Vitányi 的间隔比下界在 $h\asymp\sqrt n$、$g\asymp n^{1/4}$ 时给出 $\Omega(n^{3/2})$，一般三趟表的统一下界则需要进一步的波动估计。

本文给出两趟位移的统一非渐近上界，并将首趟位移波动与圆弧计数波动用于所有合法三趟表。由显式表族达到上界、由每张合法表满足统一下界，确定两种计费下的最优平均成本阶。确定性部分采用经典的 footrule 与逆序数关系，圆弧计数结构采用 Janson–Knuth 的构造。文献的具体对应及贡献陈述见[相关工作与参考文献](05_相关工作与参考文献.md)。
